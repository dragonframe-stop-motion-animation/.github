## Troubleshooting Common Issues

Install issues? Test tethering in the camera manufacturer's utility first, then reconnect inside Dragonframe.  
Performance problems? Reduce live view quality, capture to a local SSD, and close other USB-heavy applications.  
License/activation? Check the Dragonframe licence file and ensure the machine date is correct.  
Compatibility? Update the camera firmware when frames fail to download after a camera update.  
Update failures? Restart the capture session and reconnect the camera if the frame stream stalls.
